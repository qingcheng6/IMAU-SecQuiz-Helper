# 连续答题精简版

更新油猴中的两个现有脚本并刷新：记录脚本 `quiz-helper.user.js` 1.4.0，DeepSeek 脚本 `deepseek-hints.user.js` 1.5.0。保留原名称，避免重复安装。Key、题库、错答记忆沿用。

## 使用

右下角点击“开始连续答题”。默认自动选择、自动提交、返回首页后自动开始下一轮。随时点“暂停答题”停止。

- 已知题直接匹配，不调用 AI；未知题请求 DeepSeek，有错答记录则试未排除候选。
- 勾选确认后等待约 80 毫秒提交，100 毫秒轮询；多选仍逐项等待组件更新。实际耗时还取决于浏览器和服务器。
- 必须等服务器判分后才继续下一题，明确答错或超时后自动重开。网络/存储异常暂停；开始按钮失效最多重试三次。
- 左侧只保留“导出题库”“导入题库”两个操作按钮，持续自动采集。
- 展开“最后一道问题题”可看到题干、全部选项、实际提交和原因。返回首页甚至刷新后仍保留，正常答对其他题不会覆盖它。
- 展开“待确认题目”可看到没有答案的题，而不必在303条记录里猜是哪一道。
- 想亲自纠正最后的问题题：在右下角 API 设置里勾选“最后的问题题再次出现时交给我作答”。遇到该题时手动选择并提交，之后自动继续；本题答对后也恢复自动匹配。

保留的错误题只有最近一道；每题的错答组合仍在题库内。不能保证 AI 答案正确；多选会排除错误组合，不把每个成员都认定为错。

首次使用时，在 API 设置保存 Key，测试连接后开始。Key 仅保存在脚本管理器，不随题库导出。只发送当前题目和选项给 DeepSeek。

测试命令：`node --test test.cjs test-deepseek.cjs test-saved-multiple.cjs test-submit.cjs`。本地测试通过后仍需在线验证自动重开和真实延迟。
